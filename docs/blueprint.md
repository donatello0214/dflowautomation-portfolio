# **App Name**: DFlowAI Portfolio

## Core Features:

- Interactive Project Showcase: Display AI automation, CRM workflows, and integration systems projects in an interactive grid format with neon card visuals that trigger a modal upon clicking.
- Dynamic Blog Display: Blog posts on AI and automation topics displayed in modal windows with soft shadows and glowing borders.
- AI-Driven Content Generation Tool: Leverage AI to assist in drafting and optimizing blog content and project descriptions. Epifanio can provide input to the tool on desired length, tone, and target keywords to optimize the content accordingly.
- Tech Stack Scroller: Showcase technologies used (OpenAI, Firebase, Make.com, etc.) in a continuously scrolling banner with parallax effects.
- Contact Form with AI Assistance: Minimalist contact form with pulsing submit button and optional AI-driven analysis of messages to determine intent and urgency.
- Automatic Sitemap Generation: Automatically generate sitemap.xml and robots.txt to improve SEO. Additionally automatically generate RSS and JSON feeds
- AI Neural Network Background: Implement the Three.js holographic AI neural network as a dynamic, interactive background to create an immersive, futuristic atmosphere.

## Style Guidelines:

- Primary color: Light Blue (#ADD8E6) evokes technology and intelligence in a light scheme.
- Background color: Very light blue (#F0F8FF), close in hue to the primary, for a clean and bright feel in the light color scheme.
- Accent color: Violet (#EE82EE) is used for hover animations and highlights, providing contrast and visual interest.
- Headline font: 'Orbitron', a geometric sans-serif font to create a futuristic look for titles and headings.
- Body font: 'Inter' sans-serif font for a clean and readable user experience.
- Use neon-glowing icons for interactive elements, creating a cybernetic style.
- Fully responsive layout with modal windows for project details and blog posts, ensuring usability across devices.
- Incorporate glowing neon animations, smooth scroll, section fade-in transitions, and ripple effects for an immersive, interactive experience.
